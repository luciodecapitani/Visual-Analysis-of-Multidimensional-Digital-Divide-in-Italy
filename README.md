# Reproducibility Instructions

To reproduce the results presented in the submission **"A lattice-based visual analysis of multidimensional digital divide in Italy"**, please follow the steps below:

1. Download all the files in this repository and save them in a folder (e.g., `Dig_Div_Italy`).
2. Open **R** and set `Dig_Div_Italy` as your working directory.
3. Install the CRAN package `poseticDataAnalysis` (if it is not already installed).
4. Open the script `Digital_Divide_Italy_GitHub.R` and run it.

The script will reproduce all the numerical results and figures presented in the submission.
